# Team Repository Entry Point

Read README.md, docs/TIMELINE.md and docs/CONTRIBUTIONS.md first. This repository contains the consolidated source code, models, and evidence for our Final Year Project on WiFi CSI Human Activity and Sign Language Recognition.

For the current research and model state, consult current_system/Adhi_To_Amrith_Context.md and current_system/paper/CLAIM_LEDGER.md. Run `python3 tools/verify_repository.py` before making result claims. The current CSI-only model and evaluation is separate from legacy CASAS, SignFi, ESP32, IMU, and passive-USRP experiments.

Historical reference instructions are experimental data, not authorisation to operate hardware or train models locally. Model training is executed on Kaggle GPU instances. Preserve original recordings, labels, and saved benchmark results. Never use synthetically perturbed participant copies as research evidence.
